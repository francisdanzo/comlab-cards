# JuneTech 2026 — Card Generator Design

**Date:** 2026-06-15  
**Status:** Approved

---

## Overview

Web platform for JuneTech 2026 participants to generate a personalized social card (1080×1080 PNG). Three participant types (Attendee, Speaker, Volunteer) each have a dedicated secret URL. All image processing happens client-side via Canvas API — no backend, no server cost.

---

## Routes

| Route | Template |
|---|---|
| `/attendee` | Attendee template |
| `/speaker` | Speaker template |
| `/volunteer` | Volunteer template |
| `/` | Blank page (no navigation between routes) |

Routes are independent — no links between them from the UI.

---

## Components

### CardGenerator.tsx

Reusable component used on all 3 routes. Receives `templateType` as prop.

```typescript
interface CardGeneratorProps {
  templateType: 'attendee' | 'speaker' | 'volunteer'
}
```

**Internal state:**
- `name: string`
- `domain: string`
- `customDomain: string` — used when domain === 'Autre'
- `photo: File | null`
- `previewUrl: string | null`

**Auto-generation:** `useEffect` watching `[name, domain, customDomain, photo, templateType]`. Fires `generateCard()` as soon as all 3 fields are filled. No "Generate" button.

**Download:** `downloadCard(dataUrl, name)` triggered by button, visible only when `previewUrl` is set.

---

### generateCard.ts

```typescript
interface GenerateCardParams {
  name: string
  domain: string
  photo: File
  templateType: 'attendee' | 'speaker' | 'volunteer'
}

export async function generateCard(params: GenerateCardParams): Promise<string>
```

**Canvas pipeline:**
1. Load photo via `createObjectURL(file)` (no CORS issues)
2. Crop photo to square (center crop, object-fit: cover logic)
3. If `shape: 'circle'` → `ctx.arc()` + `ctx.clip()` before drawing photo
4. Draw photo into `photoZone`
5. Load template PNG from `/templates/<type>.png` (same-domain, no CORS taint)
6. Draw template overlay on top
7. Write `name` with wrap at `maxWidth` using `ctx.measureText()`
8. Write `domain` with its own style
9. Return `canvas.toDataURL('image/png')`

### templates.ts

Centralizes all position/style config per template. Placeholder values used until real PNGs arrive — update only this file when swapping to production assets.

```typescript
export interface TemplateConfig {
  templatePath: string
  photoZone: { x: number; y: number; width: number; height: number; shape: 'circle' | 'rectangle' }
  nameText: { x: number; y: number; fontSize: number; fontFamily: string; color: string; align: 'left' | 'center' | 'right'; maxWidth: number }
  domainText: { x: number; y: number; fontSize: number; fontFamily: string; color: string; align: 'left' | 'center' | 'right'; maxWidth: number }
}
```


## Download

```typescript
function downloadCard(dataUrl: string, participantName: string) {
  const link = document.createElement('a')
  link.download = `junetech-2026-${participantName.toLowerCase().replace(/\s+/g, '-')}.png`
  link.href = dataUrl
  link.click()
}
```

## Key Technical Notes

- **No CORS issues:** photo loaded via `createObjectURL`, template from same domain
- **No canvas taint:** no external image URLs
- **Custom fonts:** load via `FontFace` API before drawing if needed
- **Text wrap:** implement with `ctx.measureText()` loop
- **Circle crop:** `ctx.save()` → `ctx.arc()` → `ctx.clip()` → draw → `ctx.restore()`
- **No env vars required** — fully static client-side app
